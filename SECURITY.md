# Security Policy

## Reporting a vulnerability
Please do not open a public issue for a security problem in orch-pilot. Report it privately through GitHub's private vulnerability reporting by choosing "Report a vulnerability" under the repository's Security tab. A maintainer will acknowledge your report and follow up with you privately.

## Supported versions
Orch-pilot has no numbered releases, so only the latest `main` branch receives security fixes. Fixes land as pull requests under the process described in [HARNESS.md](HARNESS.md).
