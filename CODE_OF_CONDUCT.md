# Code of Conduct

## Our standards
Be respectful and patient with everyone who works in this repo, whether they are a person or an agent runner. Keep feedback on issues and pull requests specific, kind, and focused on the work rather than the person. Say plainly when something is wrong or unclear, and back it up with real output instead of guesses.

## Reporting
If you see a problem, open an issue or leave a comment on the relevant pull request so a human can see it. Nothing merges without a human, so every report gets a person's attention before any change lands. For how work and escalations move through this repo, including the `agent-blocked` label, read [HARNESS.md](HARNESS.md).
